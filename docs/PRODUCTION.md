# Production architecture and limits

The runner accepts title, brief, voice (Warguy default), target minutes and render profile. Production is split into plan, speech and render jobs. Research and generated responses are saved; speech accepted by local transcript checks is checkpointed after every scene.

## Free-tier behavior

Gemini is used only for text. No image/video/TTS API spending is required. Model IDs outside the conservative allowlist require explicit confirmation as free. Actual provider quotas depend on the project and can change. Configure them in AI Studio and the repository variables. Local pacing is at least 65 seconds between request starts, with a rolling 24-hour budget; this deliberately does not pretend every quota resets after one minute. Transient retries are bounded; daily quota exhaustion exits with code 75. The repository's concurrency group prevents overlapping pipeline jobs here, not calls from unrelated applications.

The text request budget includes failed attempts. Full documents are bounded before sending. Outputs with MAX_TOKENS are rejected. No unknown or paid fallback is selected automatically. Source extracts and scripts are cached independently.

## Narration

Chatterbox Original is pinned to upstream commit 5de7a54aa4e5e2baadb0182dde554908b48b85c2. Reference recordings and the initial voice implementation were taken from the owner's Top10-Movies commit 5daddc9c891dc39664e47084405223daccb53673. No Top10-Movies files were modified. The code is adapted to this pipeline's core utilities.

CPU PyTorch 2.6.0 and torchaudio 2.6.0 avoid accidentally downloading CUDA packages. Phrase transport is bounded to 45 words. One take is generated by default; failed speech checks can trigger bounded regeneration. The narrator does not switch engines or voices automatically. Spoken pronunciation corrections are separate from written captions. Audio is checked for nonfinite/silent samples, runaway duration, transcript coverage, missing beginnings/endings, and repeated/extra speech.

Captions use transcript-assisted word alignment to preserve the written script, with interpolated spans reported in QA. This is not phoneme-level forced alignment. Proper names and complex dates still need editorial listening.

## Visuals

Commons discovery rejects unknown/restricted license metadata and low-resolution images. Sources, artists, licenses, modifications and file URLs are recorded. A minimum number of distinct images is required; a missing scene may use a labeled geographic map. A production report identifies map fallbacks. Automatic text search cannot guarantee historical relevance. Review the included contact sheet and the completed film.

Natural Earth modern country polygons are location references, not historical boundary reconstructions. Scott Buckley soundtrack credits are included. Synthetic low-frequency chapter accents are generated locally.

## Output and review

1080p cinematic output uses moving stills, gentle grading/vignette, chapter and date typography, short captions with highlighted keywords, a ducked music bed and two-pass audio loudness normalization. Draft output is 540p. Per-shot rendering bounds FFmpeg memory use. Final output is decoded and checked for stream presence, duration mismatch and unexpected black intervals.

Full credits must remain available when sharing. No YouTube upload occurs. Complete attribution is also rendered into visible video end credits. The supplied attribution page remains available for convenient reference.

## Honest validation record

See VALIDATION.md for measured test results and comparisons. A real API or full video run is only marked successful after its actual result is inspected. Unit tests and fixture rendering do not establish Gemini account access or complete documentary quality.

## Portable runner media setup

Media setup uses installed FFmpeg/ffprobe when suitable, otherwise a SHA-256-verified portable FFmpeg 8.1.3 build with libass. It avoids unbounded package-mirror installation. DejaVu fonts and their license are bundled so the map, thumbnail and subtitle typography are consistent across runners.
